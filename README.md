📚 Projeto React: Técnicas de Estilização
Este projeto demonstra diferentes abordagens para estilização em React, explorando conceitos aplicados em sala de aula.

🎯 Técnicas Abordadas
1. CSS Global
Estilos aplicados globalmente em toda a aplicação.

Definido em um arquivo único (ex: global.css) e importado no componente principal.


2. CSS de Componentes
Estilos específicos para cada componente.

Mantido em arquivos separados (ex: Button.css para Button.jsx).

3. CSS Inline
Estilização direta via atributo style em elementos JSX.

Útil para ajustes rápidos e dinâmicos.

4. Classes Dinâmicas
Aplicação condicional de classes usando JavaScript.

Pode ser facilitada pela biblioteca classnames.

5. CSS Modules
Escopo local automático para evitar conflitos de classes.

Gera classes únicas para cada componente.
